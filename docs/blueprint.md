# **App Name**: Nomad Nest

## Core Features:

- Property Listings: Browse available rental properties with detailed descriptions and photos.
- Search and Filters: Find properties based on location, price range, amenities, and other criteria.
- Interactive Maps: Display property locations on a map for easy browsing. This includes integration with map service APIs to display the exact location.
- User Profile Management: Allow users to create and manage their profiles to save favorite properties, store payment methods, and manage communications. However, user authentication features should be deferred until a later stage.
- AI-Powered Destination Guide: Recommend a location based on your desired lodging type, desired ammenities, planned activities.  The LLM is used as a tool.
- Image gallery: View each location's gallery of interior and exterior images

## Style Guidelines:

- Primary color: Soft coral (#F08080) for a welcoming and inviting feel.
- Background color: Light beige (#F5F5DC), very desaturated, same hue as primary.
- Accent color: Dusty rose (#D2691E), saturation increased compared to primary.
- Body and headline font: 'PT Sans', sans-serif, for a modern, clean, and accessible look.
- Use simple, line-based icons for easy recognition and a modern aesthetic.
- Implement a clean and responsive grid-based layout for optimal viewing on various devices.
- Incorporate subtle transitions and animations to enhance user experience without being distracting.
